# Responsive Repair Lab demo

这是一个原创、离线可打开的 HTML/CSS/JS 响应式 UI 演示，不是真实客户案例，也不含用户或雇主资产。

直接双击 `index.html`，或使用任意静态文件服务器访问。页面不需要安装依赖。

- “修复前”故意保留长标题、价格行和底部操作栏的横向溢出。
- “修复后”使用可换行标题、可收缩布局、安全区间距和可见键盘焦点。
- 375px 和 1440px 均已做本地浏览器检查；静态演示不代表所有真实设备。

完整检查清单、适配记录和可复制片段不包含在公开演示入口中。购买咨询请回到仓库根目录的 README 创建 Issue，切勿在 Issue 发布付款码或个人敏感资料。
