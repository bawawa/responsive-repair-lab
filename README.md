# Responsive Repair Lab

一个原创、离线可运行的 HTML/CSS/JS 响应式 UI 演示。它展示长标题、价格行和底部操作栏在手机宽度下如何溢出，以及修复后如何恢复；页面还提供可见焦点和键盘状态切换。

## 公开演示

可直接打开 [在线落地页](https://bawawa.github.io/responsive-repair-lab/) 或 [`demo/index.html`](demo/index.html)，也可以下载仓库后双击运行。无需安装依赖、后端、外部图片或账号。页面明确标注“原创演示，不是真实客户案例”。演示页用于免费预览；付费资料包的清单、片段和模板不放在公开仓库。
